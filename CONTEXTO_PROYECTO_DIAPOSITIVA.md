## 4. Decisiones Técnicas Clave y Mantenimiento

- **Cero Superposición (Desktop + Mobile):** Uso de CSS Grid de 3 filas (`grid-template-rows: auto 1fr auto`) en `.app-shell` para que las barras superior e inferior nunca floten sobre el contenido. En dispositivos móviles (`<= 1024px` y `<= 640px`), cada diapositiva activa hace scroll vertical limpio en 1 columna y las imágenes mantienen su proporción completa con cabezales externos.
- **Compatibilidad OpenXML en PowerPoint (`.pptx`):** El script `build_clean_pptx.py` genera el `.pptx` usando exclusivamente imágenes JPG registradas nativamente por `python-pptx` y capas PNG transparentes (`4x4 RGBA`) para los botones interactivos clicables (`click_action.target_slide`), evitando manipulación XML manual que dispare alertas de reparación en Microsoft PowerPoint.
